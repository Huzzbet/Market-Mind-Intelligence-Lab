# Market Mind Intelligence Lab Prototype

This branch is the isolated development area for the new Market Mind opportunity scanner.

## Guardrails
- Keep changes on `prototype/intelligence-lab`; do not modify `main` during prototyping.
- Mark all sample prices, scores, and signals as simulated until verified data sources are connected.
- Never commit API keys, access tokens, or other secrets.
- Keep the existing Market Mind app unchanged until the prototype is reviewed.

## Build sequence
1. Responsive dark dashboard and candidate filters.
2. Transparent multi-factor scoring rules.
3. Market-data adapters with source and timestamp metadata.
4. Valuation bands, risk notes, and research briefs.
5. Historical testing before any integration decision.
